# Gestão de Cargos e Salários - Protheus

## Visão Geral

Dashboard desenvolvido em Power BI para análise de Cargos e Salários, integrado ao ERP TOTVS Protheus, permitindo o acompanhamento estratégico da estrutura organizacional e da remuneração dos colaboradores.

## Principais Recursos

* Dashboard pronto para uso com integração aos dados do TOTVS Protheus.
* Conexão automatizada com as bases do ERP.
* Automatização de cargas de dados e processos manuais recorrentes.
* Indicadores estratégicos para Gestão de Pessoas e Recursos Humanos.
* Análise de cargos, salários e estrutura organizacional.
* Material complementar para download e edição.
* Exemplos práticos de fórmulas e funções DAX aplicadas a dados do Protheus.
* Modelagem de dados voltada para cenários corporativos.
* Dashboards interativos para apoio à tomada de decisão.

## Tecnologias Utilizadas

* Power BI
* DAX
* Power Query
* SQL
* TOTVS Protheus

## Benefícios

* Redução do trabalho manual na geração de relatórios.
* Maior confiabilidade das informações.
* Visão consolidada da estrutura salarial.
* Apoio à gestão estratégica de pessoas.
* Monitoramento de indicadores de RH em tempo real.
